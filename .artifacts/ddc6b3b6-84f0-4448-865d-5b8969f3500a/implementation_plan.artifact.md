### 2. Data Provenance Audit (Fixed)

Every relevant adapter in `backend/app/adapters.py` will be updated to tag records correctly:
- **`real`**: Data fetched live from Copernicus, Argovis, or ERDDAP.
- **`cached`**: Data loaded from local `.nc` or `.json` sample files.
- **`synthetic`**: Data generated by `_synthetic_value` or hardcoded demo values.
- **`unavailable`**: Explicit status for datasets where no data is served.

### 3. Proposed UI Changes
- **3D Water Column Panel:** Port the Three.js water column renderer from ARGO's `index.html` to the profile panel in `index2_corrected.html`.
- **Platform Track Layer:** Add a Three.js polyline layer to show the drift track on the globe when a platform is selected.
- **Dynamic Provenance Badges:** Add labels (e.g., "Synthetic", "Cached") to the observation and model panels based on the `data_source` field.
